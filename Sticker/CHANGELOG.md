# Stickers Changelog — سجل إصدارات الستيكرات

## [stickers 1.0.0] — 2026-11-08 — أول إصدار (دائم)

- **إضافة:** 65 SVG دائمة (5 فئات × 13): وجوه / حيوانات / أشياء / رموز / ملاحظات، مع `stickers.json` ثنائي اللغة (en/ar).
- **إدماج:** تبويبات في منتقي الغرف والخوادم + أكواد `:sticker-NN:` + عرض 44px (وحدها 64px).
- **GIF:** دعم رابط `https://…/image.gif` مباشر + زر بحث Tenor (مجاني بدون مفتاح) — بلا API وبلا تعقيدات.
- **تعاون:** `public/sticker/` هي نسخة التشغيل؛ `Sticker/` هو المصدر المرجعي.
