# mic_ev2 — قفزة Major (AI-lite + fallback)

> **الحالة:** خطة تطوّر (ev1 الحالي). تتكرر بعد ev2 بعد ذلك `mic_ev2.1 … mic_ev2.9 → mic_ev3` بنفس النمط.

- **الجديد:** نموذج AI خفيف (ONNX-lite / TensorFlow.js، < 2 MB): مزح صوتي تعلّمي يرفع التقليل دون حاجة لرفع FFT، مع fallback تلقائي إلى ev1 عند أي فشل.
- **الفصل المعماري:** `core/` للواجهة المشتركة + `model/` للأوزان + `fallback/` لعزل DSP — بما يسمح بالعودة السريعة.
- **عدسة الموارد:** النموذج يعمل في WebAssembly (WASM) بموارد أقل من DSP التقليدي عند التقليل القوي.
- **التوافق:** `createMicEnhancer` تبقى، يضاف `micVersion: 'ev2'`. الإعدادات من ev1.× تُرحّل.
- **الاختبار:** نفس الاختبارات الوظيفية + اختبار إسقاط النموذج (تحذير/بديل)، وحد عبر 500 KB أوزان فقط.
