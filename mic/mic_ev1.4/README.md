# mic_ev1.4 — أنماط محادثة / موسيقى + وضع آمن

> **الحالة:** خطة تطوّر (ev1 الحالي).

- **الجديد:** 3 أنماط: `conversation` (افتراضي)، `music` (تقليل أقل وحيوية أعلى)، `lowpower` (نافذة 512 وتقليل أخف للأجهزة الضعيفة).
- **التوافق:** `micSettings.mode` في `loadMicSettings()` — يُختار من UI القائمة.
- **الاختبار:** قياس CPU لكل نمط ≤ حد متّفق عليه (مثلاً ≤ 3% CPU).
