# mic ev1.2 — أقصى نقاوة بدون قصّ الكلمات (حيّ في runtime الحالي)

> **الحالة:** فعّالة في `mic/mic_ev1/src/mic-enhancer.js` + `public/js/room/mic-enhancer.js`
> (نفس نمط ev1.1: الإصدار الحي في نقطة دخول ev1). `MIC_VERSION = 'ev1.2'`.

- **مقياس أملس:** RMS بـ EWMA + peak-hold يتحلّل — البوابة وAGC لم يعودا
  يضخّان مع كل عابر صوتي.
- **مهلة البوابة (hangover):** تُغلق البوابة فقط بعد `gateHoldMs` من الصمت،
  فنهايات الكلمات لا تُقصّ (كان الإغلاق فوريًا).
- **واجهة حية:** `getLevel()` / `getConfig()` / `setBypass()` /
  `setGateThresholdDb()` — تتغيّر الإعدادات دون إعادة بناء الرسم أو قطع المكالمة.
- **CPU حقيقي:** يُقاس من زمن نبضة المقياس نفسه (كان دائمًا صفرًا في نسخة المتصفح).
- **أمان:** `dispose()` غير مكرر التأثير (idempotent) — استدعاؤه مرتين آمن.
- **التوافق:** كل الواجهات القديمة (`attach/setEnabled/setStrength/getStats/dispose`)
  باقية كما هي؛ الجديد إضافي فقط.
