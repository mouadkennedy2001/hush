# mic_ev1.2 — كشف صدى خفيف + راحة ريح

> **الحالة:** خطة تطوّر (ev1 الحالي).

- **الجديد:** كاشف صدى (double-talk aware) يخفف التقليل أثناء التحدث (منع قطع الكلمات) + مرشح «رياح» (نقصان نشاط دون 300 Hz بدون صوت).
- **التوافق:** `strength` تبقى، يُضاف `echoGuard` (افتراضياً on).
- **الاختبار:** متخيّل صدى + ريح؛ لا يتدهور عند غيابه.
